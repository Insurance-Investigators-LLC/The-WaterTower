# Insurance Investigators LLC

This repository is the public technology foundation for Insurance Investigators LLC.

## Purpose

The project supports the business by organizing the technical foundation for:

- a public-facing website and contact experience
- lead and intake capture
- Microsoft 365-based process automation
- document management and case workflow support
- standardized investigation and reporting templates

## Planned Architecture

The initial implementation is designed around a Microsoft 365-centered operating model:

- Website for public information and lead capture
- Microsoft Forms for intake requests
- Power Automate for workflow automation
- SharePoint for document and case organization
- Lists and reporting tools for tracking progress
- Standardized templates for investigations and reports

## Repository Scope

This repository is intended for:

- website source files
- project documentation
- workflow design notes
- automation and integration planning
- operational templates that do not contain sensitive client or case information

This repository is not intended for:

- private client data
- investigation findings
- confidential legal or medical information
- credentials, keys, or production system access
- internal operational data protected by business or legal requirements

## Project Phase

The current focus is Phase 1 MVP development:

- public website structure and messaging
- intake workflow planning
- case creation and handling process design
- document management framework
- Microsoft 365 automation roadmap

## Business Mission

Insurance Investigators LLC aims to provide verified, court-ready insurance coverage information that helps injured parties understand the real value of their case.

## Notes

This project is intended to support business operations in a secure, professional, and scalable way. Sensitive information should remain in managed business systems under appropriate access controls and retention policies.
